# 核心方向 — 先读这一页

## 状态与阅读约定

设计基线：2026-10-25。本页是目标方向的唯一精简决策入口，不表示重写已经实现。它取代早期规划中的子 Agent 独立 Session、空闲接收者需额外选择唤醒，以及强制预建索引/检查点等建议。现有实现行为仍以已有指南和代码为准。

核心工作先读本页，再按任务读取相关代码和[演进说明](evolution.md)的对应章节。不需要从聊天历史重建决策，也不必读完整文档树。本页保持在 100 行以内；决策变化时替换旧结论，不追加讨论流水账。英文是规范源，中文同步。

## 产品与设计判断

kuku 是**可嵌入、文件原生的 Rust Agent SDK**，不是事后导出内部函数的应用，也不是让用户自行组装 Agent 的组件箱。CLI、server、UI 是同一套可用运行时的薄宿主。嵌入使用不强制启动 daemon、HTTP server、子进程 CLI 或插件容器。

目标是轻量工作 Harness：低消耗、长期运行可信，人类、模型和实现共用概念。概念应直观可见，不藏在各种模式后面。增加机制前，先问它支持什么真实工作、现有概念为什么不能表达，以及是否降低总复杂度。

## 保留 kuku 的优点

- **Prompt 文本不写进 Rust 执行逻辑。** 模型可见的行为指令放在可版本化的资源/模板中；代码负责加载、渲染和组合，不在条件分支、工具实现中散落指令正文。结构化运行数据本身不是 Prompt 模板。
- **Prompt 渲染与上下文装配继续分离。** Prompt 资源负责措辞；上下文装配明确选择、排序并标记策略、Agent 身份、工具指导、Memory、Skill、已接纳历史和新输入的来源；provider 把准备好的请求转换为协议。
- 保留稳定分层、可观察装配、文件事实、原生 Skill、可配置预设/等级、宿主分离，以及有效的 provider/工具实现和测试。重写所有权与执行边界，不推倒已有正确设计。[Prompt Assembly](prompt-assembly.md)介绍现有实现，不意味着必须保留所有旧重放算法。

## 一套身份与执行模型

| 概念 | 目标含义 |
|---|---|
| Session | 包含主 Agent 及委派工作的一次持久工作会话 |
| Agent | Session 内地址：`/root`、`/root/agent1`、`/root/agent1/agent1`；拥有自己的对话与执行 |
| Turn | 该地址接纳输入后的一轮工作 |
| Step | 一次逻辑模型请求及其响应触发的工具执行 |
| ToolCall | 一个动作，可区分请求、授权、派发和结果事实 |
| Job | 后台工作的句柄，不是另一套执行器或输出副本 |

人类、模型工具与运行时使用同一个 Agent 路径。地址分配后不转交给不同工作，描述性标题可变；仅跨 Session 引用时增加 Session 身份限定。不再建立平行的隐藏 Agent UUID/别名体系。路径表达委派，不是文件位置或权限。Conversation 是该地址的对话，Attempt 是 Step 内的一次模型尝试，上下文段是稳定前缀的请求序列，不需要额外身份层级。

子 Agent 留在同一个 Session 内，独立执行与配置，不默认变成独立 Session 或 Team 框架。委派是树，获准通信可以横向发生，等待必须显式。人类与 Agent 共用可观察语义，不共享人类专属批准权。

## 输入、执行与配置

- 发送消息先持久入箱。运行中的接收者在下一安全 Step 边界接纳；**空闲接收者默认启动新 Turn**。明确停止/关闭的接收者需要授权续派。发送不等待回复；投递回执和完成状态由运行时提供，不靠模型闲聊确认。
- 批量接纳待处理输入、合并唤醒，失败时保留尚未接纳的消息；Inbox 是日志派生视图，不是第二份存储。简短指令指导有效沟通，所有权和基本执行预算由代码保证，不再调用模型判断每条消息是否重要。
- 每个 Step 准备一次：已接纳输入、有效模型选择、工具定义与上下文。技术性重试复用准备结果，后来的输入/配置留到后续边界。重试归属明确，不能多层乘法重试。
- Preset 定义工作指令/工具/默认值，Tier 选择资源路由/默认值，显式模型、思考等级和服务设置按一套明确规则覆盖。记录请求与有效选择。不支持的显式选择必须报错，不静默降低思考等级或忽略供应商特有的 fast/服务设置。
- 一次模型响应中的所有工具调用作为批次接收。独立工作并行，冲突工作安全排序，不每个调用都额外往返模型。授权覆盖最终参数、绑定工具定义；批量处理不能绕过校验或隐藏部分失败。

## 事实、输出与不可变前缀

- **已提交文件是权威，内存只是可丢弃加速。** 从一个追加 Session 日志、一个写入所有者和独立大输出文件开始。打开时有界流式恢复，运行中增量追加，不每次写入扫描历史。测量显示延迟需要时，再增加一个可验证、可重建的检查点或小偏移索引；物理分段不是起步要求。
- 明确确认输入、派发副作用和确认结果之前的提交/持久化屏障。记录必要执行事实，不记录每次内部状态变化。恢复重建事实，不恢复挂起的异步调用栈；未知副作用不自动重试。写入失败停止依赖工作，取消必须处理资源，不能只改标签。
- 工具输出用有界缓冲流式写入 Session 所属文件。首次接纳返回规则化结构摘要或有界回退结果，明确标记过滤/不完整并提供读取引用，原样保留模型实际看到的内容。不使用全局 shell hook、隐式命令改写或默认摘要 LLM。短调用与 Job 共用一次执行/输出，后续 Job 完成不是原 ToolCall 的第二份结果。
- 一个有界输出读取入口支持摘要/范围/搜索/增量，UI 查看不消耗模型输出。设定结果、输出文件和 Session 输出预算；如实说明丢失并在承诺生命周期内保留引用，不按系统临时文件过期。不要为此建设通用 Artifact 平台。
- **同一上下文段内，已提交的 provider 可见前缀不可变。** 只在首次接纳前过滤。不用今天的模板/配置/文件重新渲染历史，不回头剪枝工具结果。容量或不兼容请求头变化通过显式后继段及已记录交接处理，旧历史保留。稳定前缀提高缓存复用条件，不保证供应商缓存永远保留。

## 工作目录与 SDK 边界

工作目录是普通目录，不是 Git 仓库。主/子 Agent 默认共享它，调用者可以明确指定其他目录。核心执行、持久化、文件工具和变更记录，在有无 Git 时必须走同一条路径。Git 命令和 worktree 是可选工具/用户选择，不隐式初始化、隔离或合并。文件冲突检查依据观察到的内容/版本，不依赖 Git 是否存在。

提供可用默认值，以及明确的模型/工具/宿主适配、提交、观察、查询、取消和异步关闭接口。运行时独立于订阅者推进。不接管进程 cwd、环境变量、信号、全局日志或无关进程。每个资源有所有者；慢观察不能变成无限缓冲或已提交结果丢失。

**最小权限边界建议：** 一个异步宿主授权入口接收实际动作、Agent 身份、最终参数和执行目录，返回允许或拒绝。宿主可以自动判断，也可以先询问用户；内核保证派发前执行并记录这个决定。不要求规则 DSL、角色层级、授权记忆系统或审批工作流框架。报错、取消或必要批准不可用都不构成授权。工具授权不等于操作系统进程隔离，允许 shell 不证明其所有副作用都限制在工作目录内。具体 API 和默认策略仍待确认。

不从一切皆插件、loop 热替换、通用事件中间件、多存储后端、分布式 writer、Team 管理、workflow DSL 或任意进程透明崩溃续跑开始。WebUI 重写已弃；DSH 是契约参考，不是要复制的架构。

## 重写范围与下一可用结果

旧版目前只有用户本人使用，不需要继续维护。**重写不承担旧 API、旧地址或旧 Session 格式兼容要求。** 不为保留旧版而建设适配层、迁移或双运行时。保留源码/数据作参考不等于维护承诺，这个决定也不授权删除用户文件。

当前只改文档。推荐流程：审阅后提交方向文档，再明确创建普通重写分支/worktree；main 是参照，不是第二条开发线。

第一批可用结果是一个**使用公开 SDK 的普通 Rust 调用程序**：在普通非 Git 目录打开 Session、提交输入、执行多工具 Step、返回结果、取消/收尾，并重开新格式历史。先有 `/root`、可复用的 provider/工具和通用有界输出，CLI 使用同一公开接口。**尽早接入真实模型与真实工具，完成有用任务，不只测试问候回复。** 在实现中验证设计，不另设编码前的架构证明阶段。针对性测试保护具体契约，仅通过 mock 不代表产品可用。

SDK/类型/事件 schema、提交屏障、存储阈值、输出配额/解析器和交接细节，在下一可用结果需要前保持开放。累计 token、请求大小、磁盘字节和内存分开衡量；优化每次模型调用的有效工作和精准首次接纳，不只看命中率。[演进说明](evolution.md)保留按需使用的实现证据，不增加产品前置条件。
