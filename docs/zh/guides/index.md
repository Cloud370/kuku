# 使用指南

安装并配好 kuku 后，按具体任务查阅对应页面。

- [运行任务](run-a-task.md) — 单次执行、TUI 操作与 JSON 输出
- [管理 Session](manage-sessions.md) — 恢复对话、回溯历史、回复待决请求与保存值
- [使用 Agent](use-agents.md) — 多 Agent 协作与 Markdown 预设
- [使用 Skill](use-skills.md) — 内置用法帮助、个人与项目 Skill、发现与斜杠调用
- [管理 Memory](manage-memory.md) — 全局与项目级长期记忆
- [运行服务](run-the-server.md) — 受管本地服务与远程服务
- [排查 CLI 运行](debug-cli.md) — 查看快照、事件日志、用量与请求 trace
- [升级 kuku](upgrade-kuku.md) — 更新二进制并重连受管服务

第一次上手日常流程，先看[运行任务](run-a-task.md)。
